# 크기 축소 · 무적 이펙트 · PNG 교체 폴더 정리 — 설계

작성일: 2026-07-24
상태: **설계 합의 대기 중** (사용자 승인 후 구현 예정)

## 배경

붕어빵 러너 게임. 현재 고양이 · 붕어빵 조각 · 장애물 스프라이트는 PNG가 아니라
`js/sprites.js`에서 코드로 그려지는 픽셀아트(오프스크린 캔버스)다.
표시 배율은 `SCALE = 3`, 히트박스는 절대 픽셀값으로 정의되어 있다.

## 사용자 요청 & 결정 사항

1. **고양이 · 붕어빵 · 장애물 크기 축소** → 약 30% 축소 (0.7배)
2. **무적 상태일 때 고양이에 이펙트 추가** → 반짝임 + 무지개 깜빡
3. **나중에 PNG 파일 교체 가능하게 폴더 정리** → 자동 폴백 로더 방식

## 설계

### 1. 크기 30% 축소

- `sprites.js`에 축소 비율 `SIZE = 0.7`을 추가하고 표시 배율에 반영.
- **주의점**: 히트박스가 절대 픽셀값(예: 고양이 `x+14`, `w-30`)이라 크기만 줄이면
  판정이 어긋난다. → 히트박스 여백도 같은 0.7배로 함께 줄여 판정 비율을 유지한다.
  겉보기만 작아지고 난이도·판정 느낌은 동일.
- 장애물 히트박스 여백은 이미 `inset * S` 형태라 배율에 자동 반영됨.
  고양이 · 붕어빵(piece)의 절대값 여백만 `SIZE` 반영 필요.

### 2. 무적 이펙트 (반짝임 + 무지개 깜빡)

- 기존 녹색 오라(`_drawAura`)는 유지.
- 무적(`invincible > 0`) 동안 고양이 본체에 추가:
  - 무지개 색조(hue 회전)로 살짝 물들이고 짧은 주기로 밝게 반짝(깜빡).
  - 고양이 주위에 작은 별/반짝임 파티클이 이따금 튀어나옴.
- `game.js` 렌더에서 무적 중일 때 고양이 draw 전후로 hue-rotate 필터 + 반짝임 적용.
- 기존 `iframe`(피격 무적) 깜빡임과 충돌하지 않게 분리.

### 3. PNG 교체용 폴더 정리 (자동 폴백 로더)

폴더 구조:

```
assets/
  cat/        run0.png run1.png run2.png jump.png
  obstacles/  crate.png cone.png bush.png
  taiyaki/    red.png cream.png
  README.md   ← 파일명 규칙 + 권장 크기(px) 안내
```

- 새 파일 `js/assets.js`: 위 manifest의 PNG 로드 시도.
  - 성공 → 코드 그림 대신 그 PNG 사용.
  - 404 → 지금처럼 코드 그림 유지.
- **핵심 설계**: PNG로 바꿔도 표시 크기·히트박스는 코드가 정한 고정 native 치수
  기준으로 유지한다. PNG 픽셀 크기가 달라도 게임 판정은 흔들리지 않음.
  - 이를 위해 장애물이 이미지 픽셀폭(`o.canvas.width`) 대신 `nativeW/nativeH`를
    쓰도록 소폭 정리.
- `index.html`에 `js/assets.js` 로드 추가, 페이지 로드 시 자동 프리로드.
- PNG 미배치 상태에서도 게임은 현재와 100% 동일하게 동작.

## 영향받는 파일

- `js/sprites.js` — `SIZE` 추가, 장애물에 `nativeW/nativeH` 노출.
- `js/entities.js` — 표시 배율/히트박스에 `SIZE` 반영, 장애물 native 치수 사용.
- `js/game.js` — 무적 시 무지개+반짝임 렌더.
- `js/assets.js` — **신규**, PNG manifest + 폴백 로더.
- `index.html` — `js/assets.js` 로드 추가.
- `assets/` — **신규** 폴더 구조 + README.
