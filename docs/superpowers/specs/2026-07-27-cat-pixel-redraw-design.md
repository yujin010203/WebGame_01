# 고양이 스프라이트 픽셀 다시 찍기 (A안: 래스터화 + 임계값)

날짜: 2026-07-27

## 문제

고양이 외곽선이 흐릿하고 화질이 나빠 보인다. 원인은 확대 자체가 아니라,
`sprites.js`의 고양이가 **안티에일리어싱된 벡터 도형**(`ellipse`/`arc`/`quadraticCurve`/round-cap 선)이기 때문.
Canvas 2D는 도형 경계에 반투명 픽셀(AA fringe)을 항상 넣고, 게임은 이를
`imageSmoothingEnabled=false`로 ~2.5배 확대 → 반투명 경계 픽셀이 큰 회색 덩어리(헤일로)로 보임.

## 목표 / 비목표

- **목표:** 외곽선이 확대해도 선명한 **진짜 하드엣지 픽셀아트**로 전환.
- 현재 룩 유지: 회색 단색 실루엣(`fur=#5d6166`) + 검은 눈(`eye=#161618`), run0/1/2 + jump 4프레임.
- 화면 표시 크기·위치·히트박스 **불변**.
- **비목표:** 셰이딩/외곽라인/색 추가, 포즈 변경, 애니메이션 타이밍 변경.

## 접근법 (A안)

기존 도형 정의를 그대로 재사용하되, 렌더 결과에서 AA를 제거해 하드엣지로 만든다.

1. **해상도 상향 (`SS=2`)**: 각 프레임을 `24*SS × 20*SS = 48×40` 오프스크린 캔버스에
   기존 `drawCat` 도형을 `SS`배 스케일로 그린다. (요청한 ~40×34에 근접한 깔끔한 2배)
2. **임계값 + 색 양자화**: 그린 뒤 `getImageData`로 픽셀 순회.
   - 알파 < 임계값(약 128) → 완전 투명(`a=0`).
   - 그 외 → RGB 거리로 `{fur, eye}` 중 가까운 색을 골라 **완전 불투명**(`a=255`)으로 스냅.
   - `putImageData`로 되쓰기 → AA fringe 0, 하드엣지 실루엣.
3. **논리 치수 유지**: `cat.nativeW=24, nativeH=20` 그대로. `drawImage(img, x, y, w, h)`가
   48×40 캔버스를 기존과 동일한 `w×h`(≈60×50px)로 스케일하므로 게임 내 크기·히트박스 계산
   (`entities.js`)은 한 줄도 안 건드린다.

## 건드리는 파일

- **`js/sprites.js`** (고양이 섹션): `make`로 프레임 생성하는 부분을 `SS` 상향 + 임계값
  후처리로 교체. 헬퍼(`quantize`) 추가. 도형/포즈 정의(`POSE`, `drawCat`)는 좌표 스케일만
  적용하고 형태는 불변.
- **`js/main.js`** (시작화면 미리보기): 현재 `img.width * s` / `img.height * s`로 캔버스
  픽셀 크기에 의존 → 해상도 2배 시 미리보기가 2배로 커짐. `Sprites.cat.nativeW/nativeH`
  기준으로 바꿔 표시 크기를 고정(부수적으로 PNG 미리보기도 픽셀 크기 독립이 됨). 해상도
  변경에 따른 **필요 최소 수정**.

그 외 파일(entities.js, game.js, assets.js, css)은 불변. PNG 교체 로더는 표시 크기가
native 기준이라 영향 없음.

## 검증

1. 게임 실행 → 고양이 외곽선 선명, 회색 헤일로 없음.
2. 크기·바닥 위치·점프/런 애니메이션·히트박스 체감 동일.
3. 시작화면 미리보기 크기 이전과 동일.
