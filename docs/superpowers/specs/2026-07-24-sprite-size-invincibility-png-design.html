배경

현재 고양이 · 붕어빵 조각 · 장애물 스프라이트는 PNG가 아니라 js/sprites.js에서 코드로 그려지는 픽셀아트(오프스크린 캔버스)다. 표시 배율은 SCALE = 3, 히트박스는 절대 픽셀값으로 정의되어 있다.

결정 사항

① 크기 — 고양이 · 붕어빵 · 장애물 약 30% 축소 (0.7배)
② 무적 이펙트 — 반짝임 + 무지개 깜빡
③ PNG 교체 — 자동 폴백 로더 방식 (assets/ 폴더)

1크기 30% 축소

  • sprites.js에 축소 비율 SIZE = 0.7을 추가하고 표시 배율에 반영.
  • 장애물 히트박스 여백은 이미 inset * S 형태라 배율에 자동 반영됨. 고양이 · 붕어빵(piece)의 절대값 여백만 SIZE 반영 필요.
⚠ 주의점 — 히트박스가 절대 픽셀값(예: 고양이 x+14, w-30)이라 크기만 줄이면 판정이 어긋난다. 히트박스 여백도 같은 0.7배로 함께 줄여 판정 비율을 유지한다. 겉보기만 작아지고 난이도·판정 느낌은 동일.

2무적 이펙트 (반짝임 + 무지개 깜빡)

  • 기존 녹색 오라(_drawAura)는 유지.
  • 무적(invincible > 0) 동안 고양이 본체를 무지개 색조(hue 회전)로 살짝 물들이고 짧은 주기로 밝게 반짝(깜빡)이게 함.
  • 고양이 주위에 작은 별/반짝임 파티클이 이따금 튀어나옴.
  • game.js 렌더에서 무적 중일 때 고양이 draw 전후로 hue-rotate 필터 + 반짝임 적용. 기존 iframe(피격) 깜빡임과 충돌하지 않게 분리.

핵심 설계 — PNG로 바꿔도 표시 크기·히트박스는 코드가 정한 고정 native 치수 기준으로 유지한다. PNG 픽셀 크기가 달라도 게임 판정은 흔들리지 않음. 이를 위해 장애물이 이미지 픽셀폭(o.canvas.width) 대신 nativeW/nativeH를 쓰도록 소폭 정리.
