# assets/ — 스프라이트 PNG 교체 폴더

이 폴더에 아래 이름 규칙대로 PNG를 넣으면, 게임이 코드로 그리던 그림 대신
**그 PNG를 자동으로 사용**합니다. 파일이 없으면 지금처럼 코드 그림이 그대로 나옵니다.
(코드 수정 불필요 — 파일만 넣으면 됨)

## 파일 이름 규칙 & 권장 크기

표시 크기·충돌 판정은 코드가 정한 고정 치수 기준이라, PNG 실제 픽셀 크기가 달라도
게임 밸런스는 바뀌지 않습니다. 아래 "권장 px"는 픽셀아트가 가장 또렷하게 보이는 크기이며,
2배·3배 고해상도로 넣어도 됩니다. (게임은 확대 시 부드럽게 뭉개지 않는 픽셀 방식 사용)

### cat/  — 고양이 (권장 24 × 20 px)
| 파일 | 용도 |
|------|------|
| `cat/run0.png` | 달리기 프레임 1 |
| `cat/run1.png` | 달리기 프레임 2 |
| `cat/run2.png` | 달리기 프레임 3 |
| `cat/jump.png` | 점프 |

### obstacles/  — 장애물
| 파일 | 용도 | 권장 px |
|------|------|---------|
| `obstacles/crate.png` | 나무 상자 | 20 × 22 |
| `obstacles/cone.png`  | 고깔       | 22 × 24 |
| `obstacles/bush.png`  | 덤불       | 22 × 20 |

### taiyaki/  — 붕어빵 조각 (권장 20 × 14 px)
| 파일 | 용도 |
|------|------|
| `taiyaki/red.png`   | 팥 붕어빵 |
| `taiyaki/cream.png` | 슈크림 붕어빵 |

### bg/  — 배경 & 바닥 (가로 반복 스크롤)
| 파일 | 용도 | 권장 px |
|------|------|---------|
| `bg/sky.png`    | 배경(하늘·언덕·구름). 가로로 반복되며 느리게 스크롤. | 높이 330, 폭 자유 |
| `bg/ground.png` | 바닥 타일. 가로로 반복되며 배경보다 빠르게 스크롤.   | 높이 70, 폭 자유  |

세로는 각 영역 높이(하늘 330 / 바닥 70)에 자동으로 맞춰 채워지므로, 폭만
가로로 이어지게(좌우 끝이 매끄럽게) 만들면 이음새 없이 스크롤됩니다.

### ui/  — 생명 하트 & 버튼 (HTML 요소)
| 파일 | 용도 | 비고 |
|------|------|------|
| `ui/heart-full.png`  | 남은 생명 | full/empty **두 장 모두** 있어야 적용됨 |
| `ui/heart-empty.png` | 잃은 생명 | 한쪽만 있으면 ❤ 이모지 폴백 유지 |
| `ui/button.png`      | 버튼 배경 틀 | 버튼 크기에 맞춰 늘어남; 글자는 코드로 유지 |

- 하트 권장: 정사각(예 48×48), 투명 배경.
- 버튼은 배경만 교체되고 "게임 시작"/"다시 시작" 글자는 그대로 얹혀 나옵니다.

## 팁
- 투명 배경(알파 채널) PNG 권장.
- 캐릭터가 바라보는 방향은 **오른쪽 기준**(진행 방향은 왼쪽으로 스크롤).
- 일부만 교체해도 됩니다. 예: `cat/`만 넣으면 고양이만 PNG, 나머지는 코드 그림.
- 교체 목록·경로는 `js/assets.js`의 `MANIFEST`에서 관리합니다.
